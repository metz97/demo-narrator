# Hint — task 92191, "Calculation overrides"

The A1-A3 override feature exists ONLY on composite / layered assemblies, never on
simple objects. Use the composite assembly with reference code **REF02** (it already
has an override applied).

Steps to demonstrate:

1. Go to Projects and open the "1 Million United Kingdom Pound Project" project.
2. Open its "Carbon assessment".
3. Hover the override icon (`a1a3-override-icon`) next to REF02 to show the tooltip
   that this value has been manually overridden.
4. Open REF02's row menu (the kebab / MoreVert button on the REF02 row) and choose
   "Edit details".
5. In the modal, click "Build composite assembly", then click "Next".
6. Point out the "Override" checkbox beside the "A1-A3 kg CO2e" field — this is the
   feature: enabling it lets the user type a measured A1-A3 value that replaces the
   calculated one.
7. Click "Cancel" to close without changing any data.
